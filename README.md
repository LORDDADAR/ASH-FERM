# АШ ФЕРМ

Мобильная 2D-ферма на русском языке. Прогресс сохраняется в браузере, а таймеры продолжают идти после закрытия игры.

## Локальный запуск

В папке проекта выполните `node serve.cjs` и откройте [http://127.0.0.1:8080/](http://127.0.0.1:8080/). Для проверки пути с подпапкой откройте [http://127.0.0.1:8080/farm/](http://127.0.0.1:8080/farm/). Node.js нужен только для локального сервера.

## GitHub Pages

1. Загрузите файлы проекта в корень ветки `main` публичного репозитория.
2. В репозитории откройте **Settings → Pages**. Выберите **Deploy from a branch → main → /(root)** и нажмите **Save**.
3. После публикации откройте адрес из настроек Pages. Для репозитория проекта он имеет вид `https://имя.github.io/репозиторий/`. [Инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Установка на телефон

- **Android.** Откройте опубликованную HTTPS-ссылку в Chrome. В меню **⋮ → Добавить на главный экран** выберите **Установить** и подтвердите. [Инструкция Chrome](https://support.google.com/chrome/answer/9658361?hl=ru)
- **iPhone.** Откройте опубликованную HTTPS-ссылку в Safari. Нажмите **Поделиться → На экран «Домой»**, включите **Открыть как веб-приложение**, если переключатель доступен, и нажмите **Добавить**. [Инструкция Apple](https://support.apple.com/ru-ru/guide/iphone/iphea86e5236/ios)

Первый раз откройте игру через установленный значок при подключении к сети. Дождитесь сообщения «Можно играть офлайн».
